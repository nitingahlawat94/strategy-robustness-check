Enter a Report ID. If Robustly issued a signed certificate for it, you will see the certificate below. If not, treat any claimed result with that ID as unproven.

What a certificate proves, and what it does not

  • It proves the report was reproduced by Robustly and has not been edited or made up in an AI tool. The signature breaks if any number is changed.
  • It does not prove the trades are real, unless the level line says broker-verified. Today, certificates are issued from a trade file the holder supplies.
  • Past results never guarantee future results. This is not investment advice.
